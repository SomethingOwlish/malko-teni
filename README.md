## Как поднять (один раз, ~10 минут)

1. На GitHub создай репозиторий (**New repository**). Назови его нейтрально, например `nsd-notes`, без слов «малкавиан» и «игра».
2. Загрузи туда **содержимое** этой папки: **Add file → Upload files**, перетащи всё, включая папки `assets`, `data` и т. д. Файл `library.json` сюда **не клади**.
3. Открой **Settings → Pages → Source: Deploy from a branch**, выбери ветку `main` и папку `/ (root)`, нажми **Save**. Через минуту появится адрес сайта.
4. Создай токен для пульта: **Settings (профиля) → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
   - Repository access: **Only select repositories**, выбери этот репозиторий.
   - Permissions → Repository → **Contents: Read and write**.
   - Срок: до конца игры.
5. Открой пульт. В «Настройках» впиши логин, имя репозитория, ветку `main` и токен. Там же выбери файл `library.json`.

Токен и библиотека хранятся только в браузере, где ты их ввела. На другом устройстве введи их заново. Кнопка «Забыть всё на этом устройстве» стирает их.

## Как пользоваться пультом

- Во вкладке игрока стоит галочка **«показать»** у каждого из 7 осколков и у карточек четвёртой ночи. Галочка **«полный текст»** добавляет под осколком раскрывающийся текст; при «показать» она ставится сама. Чтобы осталась только короткая фраза, сними её. В поле **аудио** вставь прямую ссылку на mp3, и в карточке появится плеер.
- **Шум Сети** — видения от других мастеров, из Малкнета, любые личные вбросы.
- Во вкладке **Ссылки** настраиваются ТГ мастеров, ТГ Илинки и клановый чат: подпись, адрес, показывать или нет. Там же общее объявление для всех.
- Точка ● на вкладке значит, что есть неопубликованные изменения. **Опубликовать** отправляет на GitHub только изменённые карточки.
- Черновик сохраняется в браузере. **Перечитать с сайта** сбрасывает его к тому, что сейчас видят игроки.

## Что важно знать

- **Публикуется только то, что отмечено.** Полные тексты всех осколков лежат в `library.json` у тебя. В репозиторий попадают только открытые осколки, у каждого игрока свой файл `data/<путь>.json`.
- На бесплатном GitHub Pages репозиторий **публичный**. Тот, кто найдёт репозиторий, увидит уже открытые осколки всех игроков. Для игры это приемлемо. Если нет, понадобится GitHub Pro (Pages из приватного репозитория) или Netlify/Cloudflare Pages.
- После публикации GitHub пересобирает сайт около минуты, плюс до минуты на опрос карточки. Новые осколки подсвечиваются меткой «новое».
- Аудио удобно класть в тот же репозиторий в папку `audio/` (ссылка `https://<логин>.github.io/<репо>/audio/файл.mp3`) или на любой хостинг с прямой ссылкой.
- Новые тексты: добавь их в `library.json` и загрузи файл в пульт заново.
