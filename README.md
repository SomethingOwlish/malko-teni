# Карточки Малкавиан — «Тени над Дунаем»

Пять карточек игроков и пульт для мастеров. Сайт живёт на GitHub Pages. Пульт работает с телефона и открывается по паролю.

## Как поднять (один раз, ~10 минут, удобнее с компьютера)

1. **Репозиторий.** На GitHub нажми **New repository**, назови нейтрально, например `nsd-notes`, и сделай **Public**.
2. **Файлы.** Нажми **Add file → Upload files** и перетащи всё содержимое этой папки. `library.json` сюда не клади.
3. **Сайт.** Открой **Settings → Pages → Deploy from a branch**, выбери `main` и `/ (root)`, нажми **Save**. Через минуту сайт заработает.
4. **Токен.** В профиле открой **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
   - Repository access: **Only select repositories**, выбери этот репозиторий.
   - Permissions → Repository permissions → **Contents: Read and write**.
   - Срок: до конца игры.
   - Скопируй токен.
5. **Ключи.** Открой пульт и нажми **Первичная настройка ключей**:
   - логин и репозиторий подставятся сами, вставь токен;
   - придумай **пароль координатора** (только для тебя) и **пароль мастеров** (для остальных мастеров);
   - выбери `library.json`;
   - нажми **Зашифровать и сохранить**.

После этого вход везде по паролю, с телефона тоже. Токен и тексты осколков лежат в репозитории только в зашифрованном виде (`data/vault.json`).

## Кто что может

| | Координатор | Мастер |
|---|---|---|
| Открывать осколки и карточки N4, полный текст, аудио | ✓ | |
| Переключать ночь (безумие на карточках растёт) | ✓ | |
| Имя, архетипы, напоминалки, объявления, ссылки | ✓ | |
| Вкидывать видения и ивенты одному, нескольким или всем | ✓ | ✓ |
| Править и убирать видения | ✓ | ✓ |
| Менять пароли, токен, библиотеку | ✓ | |

- **Видения сохраняются сразу.** Если двое вкидывают одновременно, ничего не потеряется: каждое изменение дописывается к свежей версии.
- **Осколки, ночь и профиль** копятся как черновик и уходят кнопкой **Опубликовать**. Точка ● на вкладке значит, что есть неопубликованное.
- **Подпись у видения** («кто вкинул») видят только мастера.
- **Разметка в любом тексте:** `~~ложь~~{правда}` — зачёркнуто и переписано, `[[скрытое]]` — проявляется при выделении или нажатии, `||имя||` — чёрная плашка.

## Ночи

Переключатель **Ночь** в пульте (до игры, N1–N4) меняет все пять карточек:
- фон уходит в «неправильный» цвет;
- рамки разъезжаются;
- проступает второй акцент;
- эффекты безумия появляются чаще.

После полуночи по часам телефона у игрока включается ночная палитра. Посмотреть заранее: допиши к адресу карточки `?night=4` или `?night=4&late=1`.

## Если что-то не так

- **«Неверный пароль» сразу после настройки.** Подожди минуту: сайт пересобирается.
- **«GitHub не принял токен».** Токен истёк или удалён. Сделай новый и в пульте открой **Ключи → Перевыпустить ключи**.
- **Сменить пароль мастеров.** Там же, в **Ключах**. Старый пароль перестанет работать.
- **Выйти на чужом устройстве.** Кнопка **Выйти** стирает всё с этого устройства.
